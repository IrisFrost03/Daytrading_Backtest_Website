# Project Overview

Goal:
  My goal with this project, as an amateur day-trader myself, is to build a website that I can use to back-test my day-trading strategies. Many websites on the internet cost premiums to use or for necessary features. 

Planning:
  Trello will be used as the sole planning platform. The link can be found here: 
  https://trello.com/b/zYN19qac

Inspiration:
  SureInsight - https://app.sureinsight.app/brief
  <img width="1587" height="779" alt="image" src="https://github.com/user-attachments/assets/90395f07-0237-4d9a-b268-cd2956dfe45e" />

    

    What I like:
    - Offers historical back-testing
    - Dashboard with useful information
    - Provides journaling for trades
    - Calendar view of trades
    - Import features from many popular trading platforms (Apex, TopstepX, Tradify, etc.)
    
    What I don't like:
    - Cost money for AI features
    - Back-testing is clunky, and lags at best
    - Doesn't offer S&P 500 (MES)!!!
    - Interface for adding trades manually... kind of sucks
