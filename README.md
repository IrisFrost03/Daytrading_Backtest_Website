# Daytrading_Backtest_Website

Goal:
  My goal with this project, as an amateur day-trader myself, is to build a website that I can use to back-test my day-trading strategies. Many websites on the internet cost premiums to use or for necessary features. 

Planning:
  Trello will be used as the sole planning platform. The link can be found here: 
  https://trello.com/invite/b/6ac64bd06e46b2cfbe55ab72/ATTI083e61e7dc00879b0a562976b1c71218CE7309AF/backtesting-portfolio-project
